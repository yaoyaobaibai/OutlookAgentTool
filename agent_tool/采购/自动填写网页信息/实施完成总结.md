## 🎯 功能特性

### ✅ 已实现

1. **系统选择**
   - 下拉框选择 CSMS/Acubuy/SAP
   - 显示系统详细信息
   - 系统信息实时预览

2. **流程选择**
   - 根据系统自动过滤流程
   - 显示流程描述
   - 支持多个流程

3. **程序选择**
   - 自动推荐模式（根据流程）
   - 手动选择模式（提案/表单）
   - 智能程序匹配

4. **启动管理**
   - 一键启动对应程序
   - 启动器自动最小化
   - 实时日志记录

5. **配置管理**
   - 自动创建默认配置
   - 快速打开配置目录
   - 支持动态添加系统


```
1. 选择系统 → CSMS
2. 选择流程 → 创建提案
3. 选择程序 → 自动推荐（已选中）
4. 点击"启动程序" → 启动 auto_create_proposal.py
```

## 🔧 配置说明

### system_config.json 结构

```json
{
  "version": "1.0",
  "systems": [
    {
      "system_id": "csms",              // 系统唯一标识
      "system_name": "CSMS",            // 显示名称
      "file": "systems/csms.json",      // 配置文件路径
      "icon": "🏢",                      // 图标
      "description": "说明文本",
      "programs": {                     // 可用程序
        "proposal": "auto_create_proposal.py",
        "form": "form_filler.py"
      }
    }
  ],
  "flows": [
    {
      "flow_id": "csms_create_proposal",
      "flow_name": "CSMS - 创建提案",
      "system_id": "csms",              // 关联系统
      "file": "flows/csms_create_proposal.json",
      "icon": "📄",
      "description": "流程说明",
      "recommended_program": "proposal" // 推荐程序
    }
  ]
}
```

## ➕ 添加新系统（3 步）

### 步骤 1: 创建系统配置
```bash
# 在 systems/ 目录创建
systems/new_system.json
```

### 步骤 2: 更新总配置
编辑 `system_config.json`，添加系统信息。

### 步骤 3: 重启启动器
重新启动即可看到新系统。
