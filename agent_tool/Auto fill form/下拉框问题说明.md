# ASP.NET 下拉框问题深度解析

## 🔍 问题根源

### 现象
```
日志显示：✓ select_option 成功
实际页面：下拉框没有变化
```

### 原因

ASP.NET WebForms 的下拉框 HTML 结构：
```html
<select name="ctl00$ContentPlaceHolder1$ddlSelPriceCurrCode" 
        id="ctl00_ContentPlaceHolder1_ddlSelPriceCurrCode"
        onchange="javascript:setTimeout('__doPostBack(\'ctl00$ContentPlaceHolder1$ddlSelPriceCurrCode\',\'\')', 0)">
    <option selected="selected" value="-1"></option>
    <option value="15">USD</option>
    ...
</select>
```

**关键点**：
- `onchange="javascript:setTimeout('__doPostBack(...)', 0)"`
- 当用户改变选择时，会触发 `__doPostBack()` JavaScript 函数
- `__doPostBack()` 会向服务器发送 POST 请求，更新页面状态

### Playwright 的问题

```python
# ❌ 这种方式不会触发 __doPostBack
element.select_option('15')
# 虽然 DOM 中的 value 改变了，但 onchange 事件没有被触发
# 所以服务器不知道用户改变了选择
```

## ✅ 解决方案

### 方案 1: 使用 JavaScript 直接触发

```python
page.evaluate("""() => {
    var elem = document.getElementById('ctl00_ContentPlaceHolder1_ddlSelPriceCurrCode');
    if (elem) {
        // 1. 设置值
        elem.value = '15';
        
        // 2. 触发 change 事件
        elem.dispatchEvent(new Event('change', { bubbles: true }));
        
        // 3. 触发 __doPostBack
        if (typeof __doPostBack === 'function') {
            __doPostBack(elem.id, '');
        }
    }
}""")
```

### 方案 2: 模拟真实用户操作

```python
# 1. 点击下拉框
element.click()

# 2. 等待选项出现
option = page.locator('option[value="15"]')
option.wait_for()

# 3. 点击选项
option.click()

# 4. 等待 __doPostBack 完成
page.wait_for_timeout(2000)
```

**问题**：方案 2 在 headless 模式下可能不稳定。

## 🎯 最终实现

在 `form_filler.py` 中的修复代码：

```python
if tag_name == 'select':
    # 获取元素 ID
    element_id = selector.replace('#ctl00_', 'ctl00_').replace('#', '')
    
    # 使用 JavaScript 一次性完成所有操作
    success = self.page.evaluate(f"""() => {{
        var elem = document.getElementById('{element_id}');
        if (!elem) return 'Element not found';
        
        var oldValue = elem.value;
        elem.value = '{value}';
        
        if (oldValue !== elem.value) {{
            // 触发 change 事件
            elem.dispatchEvent(new Event('change', {{ bubbles: true }}));
            
            // 触发 __doPostBack
            if (typeof __doPostBack === 'function') {{
                __doPostBack(elem.id, '');
                return 'Success with doPostBack';
            }}
        }}
        
        return 'Value not changed';
    }}""")
    
    print(f"结果：{success}")
    self.page.wait_for_timeout(1500)  # 等待服务器响应
```

## 📊 对比结果

| 方法 | DOM 值改变 | onchange 触发 | __doPostBack 触发 | 服务器更新 |
|------|----------|--------------|-----------------|----------|
| `select_option()` | ✅ | ❌ | ❌ | ❌ |
| JS `elem.value = x` | ✅ | ❌ | ❌ | ❌ |
| JS + `dispatchEvent` | ✅ | ✅ | ❌ | ❌ |
| **JS + `__doPostBack`** | ✅ | ✅ | ✅ | ✅ |

## 💡 经验教训

**不要相信 Playwright 的日志！**

```
日志：✓ select_option 成功
真相：只是 DOM 改变了，服务器没收到请求
```

**正确做法**：
1. 检查实际页面状态（通过 JavaScript）
2. 监听网络请求（确认 __doPostBack 被触发）
3. 等待服务器响应完成
