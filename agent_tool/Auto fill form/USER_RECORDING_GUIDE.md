# Acubuy 操作录音 — 用户操作指南

> **写给你的**：你只需要照着下面的步骤做一遍 Acubuy 的操作（5-10 分钟），剩下的全部由工具自动完成。
---

## 📦 你需要准备什么

| 东西 | 怎么拿到 |
|---|---|
| **Google Chrome 浏览器** | 你电脑应该已经有了；如果没有：https://www.google.com/chrome/ |
| **Acubuy 账号** | 用你平时工作的那个账号就行 |
| **5-10 分钟时间** | 不需要你写代码或者改任何配置 |

---

## 🚀 操作步骤（请按顺序做）

### 第 1 步：把 Recorder.exe 放到一个固定位置

1. 在 D 盘（或 C 盘）建一个文件夹，名字叫 `Acubuy录音`（随便放哪里都行，但**不要放在桌面**，桌面权限可能有问题）
2. 把 `Recorder.exe` 这个文件拖进这个文件夹
3. **记住这个文件夹的路径**（例如 `D:\Acubuy录音`）

> 💡 路径示例：`D:\Acubuy录音\Recorder.exe`

### 第 2 步：启动 Chrome（用特殊方式打开）

1. **关闭所有已经打开的 Chrome 窗口**（很重要！）

2. 按 `Win + R` 打开"运行"对话框

3. 输入下面这一行，**整行复制**（包括所有引号和空格）：

   ```
   "C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222
   ```

   > 如果你的 Chrome 装在不同位置，把路径换掉。最常见是 `C:\Program Files\Google\Chrome\Application\chrome.exe` 或 `C:\Program Files (x86)\Google\Chrome\Application\chrome.exe`

4. 点"确定"

5. Chrome 会打开一个**新的浏览器窗口**——这个窗口就是接下来要操作的浏览器

> ⚠️ **这一步最容易出错**：如果你没关闭其他 Chrome 窗口就运行这行命令，会报错或端口冲突。**先关掉所有 Chrome，再运行。**

### 第 3 步：登录 Acubuy

1. 在刚才打开的 Chrome 窗口里访问你平时用的 Acubuy 地址（生产环境的那个）

2. 用你的账号登录

3. 登录成功后，**导航到"创建 GR"那个页面**（不管里面现在有没有内容，先打开那个页面）

4. **不要关掉 Chrome**

### 第 4 步：启动 Recorder

1. 打开 `D:\Acubuy录音` 文件夹

2. **双击 `Recorder.exe`**

3. 屏幕上会弹出一个**黑色的命令行窗口**（cmd 窗口），显示一些文字。看着像这样：
   ```
   === Browser Action Recorder ===
   CDP port: 9222
   Output dir: recordings
   Mode: Launch new Chrome + connect
   ```
   - **这是正常的，不要关掉这个窗口**
   - 文字里可能会闪过一些彩色的输出（点击、输入的记录）
   - **窗口继续开着 = 录音继续中**

> ⚠️ **如果双击后什么都没出现**——Chrome 可能在后台，但 Recorder 没启动。请看下面的"常见问题"。

### 第 5 步：执行 Acubuy GR 创建流程（最关键）

在 Chrome 窗口里，**按你平时工作的流程**，创建一张 GR：

1. 填写 GR 表单的每个字段（PO 号、收货单号、供应商、数量、申请人、审批人、备注等）
2. **不要点提交**（如果可以的话；或者最后一步才点提交——但要记住点了什么）
3. 如果有附件上传，也照常上传
4. 完成后，**不要关 Chrome**

> 💡 **重要**：用**真实的数据**填一遍你接下来需要自动化的那个流程。工具会记下你填了哪些字段、点了哪些按钮。

### 第 6 步：停止录音

1. **回到那个黑色命令行窗口**（Recorder 那个）

2. 按 **`Ctrl + C`** 键（按住 Ctrl 再按 C）

3. 窗口会显示一些文字，类似：
   ```
   Saved X events → recordings\recorder_log_YYYYMMDD_HHMMSS.json
   ```
   - 这一行告诉你录音**保存成功了**
   - 文件名里的 YYYYMMDD_HHMMSS 是日期时间

4. 窗口可能自己关掉，也可能停着——都无所谓

> ⚠️ **如果按 Ctrl+C 没反应**——直接关掉黑色窗口也可以。文件已经保存了。

### 第 7 步：找到录音文件

1. 打开 `D:\Acubuy录音\dist\recordings\` 文件夹

2. 你会看到一个类似这样的文件：
   ```
   recorder_log_20260730_190837.json
   ```
   （数字是录的日期和时间）

3. 文件大小通常在 50 KB - 500 KB 之间

4. **复制这个文件**

> 💡 如果你看不到 `dist\recordings\` 这个文件夹，可能是 Windows 隐藏了已知文件类型。**文件夹选项** → **查看** → 取消勾选"隐藏已知文件类型的扩展名"。

## 🆘 常见问题

### Q1: 双击 Recorder.exe 后什么都没出现

**原因**：Chrome 没启动成功，或者 Recorder 启动失败了。

**解决**：
1. 重新检查第 2 步——Chrome 是不是真的打开了那个特殊窗口
2. 如果 Chrome 打开了但 Recorder 没反应——**右键点击 Recorder.exe → "以管理员身份运行"**
3. 还是不行——截图发给我

### Q2: Recorder 报错 "Cannot connect to Chrome"

**原因**：Chrome 不是用 `--remote-debugging-port=9222` 启动的。

**解决**：
1. 关闭所有 Chrome 窗口（看任务管理器 → 结束所有 chrome.exe 进程）
2. 重新做第 2 步
3. 启动 Recorder

### Q3: 我误操作了 Recorder，按了 Ctrl+C 太多次

**答**：每次按 Ctrl+C 会保存当前录音 + 退出。重新启动 Recorder 即可（不会损坏任何东西）。

### Q4: 录音文件找不到 / 不在 dist/recordings/

**答**：
- 打开 `D:\Acubuy录音\` 文件夹本身（不是 dist 子文件夹）
- 搜索文件类型 `*.json`
- 应该能找到 `recorder_log_*.json` 文件
- 如果完全没有——说明录音没成功保存，回到第 6 步重试

### Q5: 录音时间太长 / 太多无用的点击

**答**：没关系。录音文件只是"参考数据"，工具会智能筛选有用的操作。**不要为了"完美"而重录**——任何一次真实的操作录音都包含一些"噪音"，我们工具能处理。


### Q6: 录音时我的同事在我电脑上登录了其他系统，会不会录到

**答**：会。录音会捕获**所有 Chrome 活动**。如果录音期间打开了其他系统（邮件、其他内部系统），那些操作也会被录下来。**录音期间请专注 Acubuy 的操作**，其他 Chrome 标签页先关闭。
